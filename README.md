# Quebrada Fit

Página institucional responsiva da academia Quebrada Fit, no Jardim Vista Alegre, São Paulo.

## Tecnologias

- HTML semântico e acessível
- CSS responsivo com suporte a preferência por movimento reduzido
- JavaScript nativo, sem dependências ou etapa de build
- Mapa incorporado do Google Maps

O projeto pode ser aberto diretamente pelo `index.html`. Fontes, fotografias ilustrativas e o mapa são carregados de serviços externos, então precisam de conexão com a internet.

## Conteúdo

Horários e endereço seguem as informações fornecidas para o projeto. Os preços foram transcritos do material promocional enviado e precisam ser confirmados com a academia antes de publicação. Como não foi possível consultar a grade atual de aulas coletivas, equipe, eventos ou fotos reais no Instagram, essas áreas apontam para os canais oficiais ou usam imagens ilustrativas identificadas.

## Publicar no GitHub Pages

1. Envie os arquivos deste projeto para a raiz do branch `main`.
2. No repositório, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha o branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde a publicação. O endereço do site aparecerá nessa mesma página.
